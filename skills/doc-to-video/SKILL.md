# 文档视频制作

外部 agent 通过 MCP 制作或精调视频，先读 [Talker MCP 驾驶指南](../talker-mcp/SKILL.md)。

运行入口是已安装的 Talkframe App 或核心项目，不是公开能力仓库。技能位于核心项目内时，项目根目录是本文件向上三级；从公开仓库阅读时，应连接已安装的 App。不要依赖当前工作目录或其他应用仓库。用户操作入口见安装目录的 `README.md`。

## 新文档

- 确定用户实际指向的文档。在核心项目源码环境中，用 `npm run generate -- "绝对文件路径"` 完整生成；只需要先审稿时附加 `--storyboard-only`。已安装产品使用图形入口或 Talker MCP。
- 文档改写通过本机已登录的 `codex exec` 完成，保留用户配置的模型和推理设置；默认旁白使用本地 MLX + Qwen3-TTS，系统 `say` 为备用。不要把本地渲染称为全流程离线。
- 产物放在 `jobs/<id>/`。分镜的 `sourceQuote` 必须能在提取的 `source.txt` 中找到。引文匹配只证明来源存在，不证明模型总结正确，需核对数字、条件和权利。
- 已确认的来源事实优先。白皮书中的计划、可能用途与发行方声明，要保留其语气，不能写成已实现功能或法律结论。
- 先看开场和一种内容场景，再检查全片；重点检查最后要点有足够停留时间、字幕完整、人物不遮挡、音乐不过响。

## 精调已有视频

- 先读取对应任务的 `storyboard.json`、`job.json` 和 `report.json`。只改必要内容，保留其他场景与音乐选择。
- 文案、节点和数据改 `storyboard.json`；音色、语速、音乐、主题、人物开关与额外停留改任务 settings。图形界面可编辑这些内容。
- 执行 `npm run render -- <id>` 复用当前分镜，不再请求 AI 重写文章。声音按文本、音色和语速缓存；修改相关参数才重做相应语音片段。
- 故事题材先评估阅读与插画布局，优先选 `story` 故事跟读样式：横屏左文右图，竖屏上图下文，显示 narration 全文并按 captions 实际句级时间高亮，长正文分页。不要因为已有商业模板就直接套用；本样式不用流程节点和图表，diagram 为 null。
- 纯文字先评估 `poetry`（诗词朗读）或 `text-science`（文字科普）模板：`visualStyle: typography`，由 `typographyPreset` 选择诗词/知识。诗词保留原文，月亮、树与举杯人物为可复用程序粒子，不需图片；知识使用大字、公式和短要点。两者默认无音乐/片尾；nodes/metrics为空、diagram为null、移除sceneAssets。月夜造型为固定预设，不声称能自动生成任意意境。
- 默认使用成熟的商业展示动效 `visualStyle: motion`，不是儿童卡通风格。每幕通过 `visual` 指定钱包、密钥、网络等语义物体，共享粒子舞台连续变形。`classic` 保留旧文字卡片样式。
- 片尾由当前安装的品牌能力与任务设置决定；不需要片尾时使用 `brandOutro: off`。新项目启用片尾时必须保存明确的 `version`；既有项目按已保存时长与版本播放，旧任务缺少片尾字段时保持关闭，不能静默迁移。片尾计入目标与最长时长，不能挤压、移动旁白或字幕；背景音乐沿用整片淡出，不另加音效。
- 新文档先从 intro/keypoints/flow/chart/comparison/outro 中选择信息结构，再选合适视觉物体。只有现有组件无法表达用户要求时才扩展 `src/components/`，不为每篇文章重写模板。
- 运动参数集中在 `src/components/motionTokens.ts`。参考观察与精调方向见 `docs/motion-reference.md`；优先调整过渡、错峰、弹簧与稳定阅读时间的关系，而非叠加更多装饰。
- 默认音色及实际能力见 `docs/voices.md`。当前 0.6B 模型使用固定说话人，不能声称文本风格指令有效、已经训练或复刻“小帅”。精确声线克隆需要另行确定参考与实现。
- 用户给出严格时长上限时设置任务 `maxDurationSeconds`；按实际音频与导出时长验证，不能仅凭提示词声称满足。
- 用户提供的音乐放入 `public/music/`，在 `docs/music-source.md` 记录来源。该目录与生成音视频不进入 Git，单独备份即可。保持原始音轨，循环/音量处理另存文件。

## 完成条件

- 对本轮代码改动运行适当测试与 `npm run typecheck`；涉及画面、配音和时间轴时验证实际 MP4。
- `report.json` 中的自动检查不替代画面与声音审看。抽帧没覆盖的状态、未试听部分如实说明。
- 交付可播放视频、本地入口，以及此次修改后仍需用户决定的精调项。保留用户对本任务的日报排除要求。

## 模板与项目素材

- 新任务可选 `config/templates/` 中的题材模板（含故事绘本），命令行用 `--template ai-news --seconds 60`；新模板复制JSON即可，创建时冻结模板快照。
- 新闻可在页面直接粘贴正文，来源URL仅记录、不抓取。目标30～1800秒可配，30分钟保持实验性，不能声称已整片验收。
- 工作素材优先用户指定Figma节点，先读结构与截图保留原始角色；非工作网络素材记录具体来源与许可。当前本地图片格式为PNG/JPG/WebP，不自动获取和识别语义。
- `public/assets/` 存本地导入；常用素材收藏到Git管理的 `public/library/`；`public/jobs/<id>/assets/` 存作品快照。使用排名按成功作品对素材去重计数，重渲染不累加。
- 每幕在 `settings.sceneAssets` 选择 `{assetId,fit}`，默认contain；配图支持motion与story，classic需移除配图或切换风格。保存/渲染会固化本地副本。
- 通用新视频是否追加片尾以当前安装与任务设置为准；故事绘本模板默认关闭片尾，可由用户调整；切换片尾版本不改变正文模板。详见 `docs/模板扩展指南.md`。
